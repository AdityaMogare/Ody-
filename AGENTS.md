# Agent instructions

## `@ody/api-client` (Orval)

- `packages/api-client/src/generated/**` is **generated by Orval**. Never hand-edit these files.
- If hooks or API types are wrong, change the Hono route / OpenAPI schema in `services/backend`, then run `pnpm gen:contract`.
- Safe to edit: `packages/api-client/src/mutator.ts`, `src/index.ts`, `orval.config.ts`.

## Contract pipeline

`Drizzle schema` → `drizzle-zod` → `Hono OpenAPI` → `Orval` → `@ody/api-client`

Frontend must use generated hooks from `@ody/api-client`, not handwritten fetch/DTOs.
